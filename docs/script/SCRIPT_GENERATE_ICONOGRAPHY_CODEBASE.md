# Generate Iconography Codebase Script

## Overview

This Swift script generates Swift code from the iconography asset catalog. It creates type-safe access to icons through `ImageResource` extensions and generates demo enums for the demo application.

## Script File

`.script/generate-iconography-codebase.swift`

## Usage

### Direct Execution

```bash
./.script/generate-iconography-codebase.swift
```

### Using Swift Command

```bash
swift .script/generate-iconography-codebase.swift
```

## Arguments

No arguments required. The script uses the current working directory.

## Input/Output Paths

### Input
- **Asset Catalog**: `Resources/Sources/Core/Assets/Iconography.xcassets`

### Output
- **Resources Code**: `Resources/Sources/Core/Extension/ImageResource+IconographyGenerated.swift`
- **Demo Code**: `Demo/Sources/Iconography/Iconography+Generated.swift`

## Process Flow

### 1. Directory Validation

Verifies that the `Iconography.xcassets` directory exists.

**Exit Behavior**: Exits with error if asset catalog is not found

### 2. Scan for Icon Categories

Recursively scans the asset catalog to find:
- All `.imageset` directories
- Their parent folder (category name)
- Icon names (without `.imageset` extension)

**Skips**:
- Hidden files
- Root-level items
- `Contents.json` files

### 3. Generate Resources Code

Creates an extension on `ImageResource` with nested enums for each category:

**Category Mapping**:
- `Global` → `Spark` enum
- `Criteria` → `SparkCriteria` enum
- Other categories → `Spark{CategoryName}` enum

**Generated Structure**:
```swift
public extension ImageResource {
    enum Spark {
        public static let addCircleFill = ImageResource(name: "Global/AddCircleFill", bundle: .current)
        // ... more icons
    }

    enum SparkCriteria {
        public static let check = ImageResource(name: "Criteria/Check", bundle: .current)
        // ... more icons
    }
}
```

### 4. Generate Demo Code

Creates CaseIterable enums for use in the demo application:

**Generated Enums**:
- `Iconography` - For Global icons
- `CriteriaIconography` - For Criteria icons

**Structure**:
```swift
public enum Iconography: String, CaseIterable {
    case addCircleFill
    case check
    // ... more cases

    public var imageResource: ImageResource {
        return switch self {
        case .addCircleFill: .Spark.addCircleFill
        case .check: .Spark.check
        // ... more cases
        }
    }
}
```

### 5. Clean Up Old Files

Removes legacy separate files if they exist:
- `GlobalIconography.swift`
- `CriteriaIconography.swift`

## Models

### `IconCategory`

A structure representing a category of icons.

**Properties**:
- `name: String` - Category name (e.g., "Global", "Criteria")
- `icons: [String]` - Sorted array of icon names

## Helper Functions

### Naming Utilities

#### `toCamelCase(_:)`

Converts icon names to camelCase for Swift property names.

**Special Cases**:
- `"3D"` → `"threeD"`
- `"360"` → `"threeSixty"`

**Example**: `"AddCircleFill"` → `"addCircleFill"`

#### `isReservedKeyword(_:)`

Checks if a word is a Swift reserved keyword.

**Reserved Keywords**:
- `class`
- `do`
- `import`

#### `sanitizeName(_:)`

Wraps reserved keywords in backticks for use as identifiers.

**Example**: `"class"` → `` "`class`" ``

### File System Operations

#### `findIconCategories(at:)`

Recursively enumerates the asset catalog to find all icon categories and their icons.

**Returns**: Array of `IconCategory` objects, sorted by category name

**Behavior**:
- Filters for `.imageset` directories only
- Groups icons by parent folder (category)
- Sorts icons alphabetically within each category
- Skips root-level items and `Contents.json`

### Resources Code Generation

#### `getCategoryEnumName(category:)`

Maps category folder names to Swift enum names.

**Mapping**:
```
"Global"   → "Spark"
"Criteria" → "SparkCriteria"
Other      → "Spark{CategoryName}"
```

#### `generateCategoryEnum(category:)`

Generates a Swift enum with static properties for each icon in the category.

**Format**:
```swift
enum {EnumName} {
    public static let {iconName} = ImageResource(name: "{category}/{icon}", bundle: .current)
}
```

#### `generateIconographyFile(categories:)`

Generates the complete Swift file for the resources extension.

**File Structure**:
```swift
// swiftlint:disable all
// Generated using generate-iconography-codebase.swift
// DO NOT EDIT - This file is automatically generated

import DeveloperToolsSupport

public extension ImageResource {
    // Category enums here
}
```

#### `writeIconographyFile(categories:outputPath:outputFile:)`

Writes the generated resources code to the output file.

**Steps**:
1. Creates output directory if needed
2. Generates Swift code
3. Writes to file

### Demo Code Generation

#### `generateDemoCaseIterableEnum(category:enumName:)`

Generates a CaseIterable enum for use in the demo app.

**Features**:
- Each icon becomes a case
- Computed property maps cases to `ImageResource`
- Uses switch statement for case-to-resource mapping

#### `generateCombinedDemoFile(categories:)`

Generates the combined demo file with enums for Global and Criteria categories.

**File Structure**:
```swift
// swiftlint:disable all
// Generated using generate-iconography-codebase.swift
// DO NOT EDIT - This file is automatically generated

import DeveloperToolsSupport

// MARK: - Iconography

public enum Iconography: String, CaseIterable {
    // Cases and computed property
}

// MARK: - CriteriaIconography

public enum CriteriaIconography: String, CaseIterable {
    // Cases and computed property
}
```

#### `writeDemoFiles(categories:currentDirectory:)`

Writes demo files and cleans up old separate files.

**Actions**:
1. Creates demo output directory
2. Generates and writes combined demo file
3. Removes old separate files (`GlobalIconography.swift`, `CriteriaIconography.swift`)

## Error Handling

- Validates asset catalog exists before processing
- Creates directories automatically if they don't exist
- Provides clear error messages for all failures
- Exits with code 1 on errors
- Warnings for files that couldn't be removed

## Usage in Code

### Resources Code

```swift
import SwiftUI

// Type-safe access to icons
Image(.Spark.addCircleFill)
Image(.SparkCriteria.check)
```

### Demo Code

```swift
// Iterate over all icons in the demo
ForEach(Iconography.allCases, id: \.self) { icon in
    Image(icon.imageResource)
        .resizable()
        .frame(width: 24, height: 24)
}
```

## Notes

- Generated files are marked with `// swiftlint:disable all` to skip linting
- Files include DO NOT EDIT warnings
- Icon names are converted to camelCase for Swift conventions
- Reserved keywords are automatically escaped with backticks
- The script is idempotent - running multiple times produces the same output
- Demo enums are CaseIterable for easy iteration in UI
- All icons are sorted alphabetically within their categories

## Related Files

- Foundation framework (part of Swift standard library)
- DeveloperToolsSupport (used in generated code for `ImageResource`)
- No external dependencies required

## Execution Order

This script should be run **after** `generate-iconography-assets.swift`:

1. First: `generate-iconography-assets.swift` - Organizes icon assets
2. Then: `generate-iconography-codebase.swift` - Generates Swift code from organized assets
